# Harsh Mahajan — Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev

## Build for production
    npm run build      # outputs to /dist

## Deploy
- **Vercel / Netlify**: import the repo (or drag-drop the project). Build command `npm run build`, output dir `dist`.
- **GitHub Pages**: push `dist/` to a `gh-pages` branch (base path is already relative).

## Edit content
All text (skills, experience, education, projects, links) lives at the top of `src/App.jsx`.
Replace the photo at `src/assets/harsh.jpg`.
